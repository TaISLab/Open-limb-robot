README – CAD MODEL OF THE ON-LIMB ORBITING ROBOT
============================================================

1. RESOURCE TITLE

CAD model and complete mechanical assembly of the On-Limb
Orbiting Robot.

2. ASSOCIATED PUBLICATION

On-Limb Orbiting Robot: Proprioceptive Diameter Estimation
and Orthogonal Grip–Orbit Control

5. GENERAL DESCRIPTION

This resource contains the complete mechanical assembly of
the on-limb orbiting robot described in the associated
publication.

The complete assembly and its referenced component files are
provided in the following compressed archive:

OnLimbOrbitalRobot.zip

The original and official file names used during the
development of the robot have been preserved.

6. SOFTWARE USED

Software: SOLIDWORKS 2024
Edition: Academic Edition
Software licence: Academic licence provided by Universidad
de Málaga.

7. FILE ORGANIZATION

The file OnLimbOrbitalRobot.zip contains the complete
mechanical assembly and its associated component files.

Users should preserve the original directory structure and
file names when extracting the archive, as changing their
names or locations may affect the references between the
assembly and its components.


8. INSTRUCTIONS FOR USE

1. Download and extract the complete compressed archive.
2. Preserve the original directory structure.
3. Open the main assembly file using SOLIDWORKS 2024 or a
   compatible version.
4. Allow SOLIDWORKS to resolve the referenced component files
   from the extracted directory.

9. COMPATIBILITY

The files were created and verified using SOLIDWORKS 2024,
Academic Edition.

Compatibility with earlier SOLIDWORKS versions is not
guaranteed. Opening the files with a later version may update
their internal format and prevent subsequent use with
SOLIDWORKS 2024.

10. PURPOSE

The CAD files are provided to support the understanding,
inspection and reproducibility of the mechanical design
presented in the associated scientific publication.
